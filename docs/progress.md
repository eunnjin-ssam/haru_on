# 진행 상황

다른 컴퓨터나 새 대화에서 이어서 작업할 때 이 문서부터 읽는다. 단계를 마칠 때마다 고친다.

## 끝난 단계
- **1단계 (2026-10-16)**: Firestore 구조(`docs/data-model.md`), 보안 규칙(`firestore.rules`), 규칙 자동 시험 65개(`tests/`).
  규칙은 Firebase 프로젝트 `our-class-2026`에 게시됨.
- **2단계 (2026-10-16)**: 학생 번호+PIN 로그인(`index.html`), 교사 Google 로그인과 교사 등록 안내,
  기본 설정 저장, 학생 명단(붙여넣기 등록, PIN 발급·재설정, 이름 고치기, 전학 처리·되돌리기, PIN 카드 인쇄).
  에뮬레이터에서 전체 흐름 확인함.
- **3단계 (2026-10-17)**: 학생 대시보드(지갑 포인트·오늘 남은 할 일·진행 바), 기분 고르기(6종+직접 쓰기),
  기초미션(하루 5문제·무작위·재시도 없음·맞힌 개수만큼 1점), 1인1역(했어요→요청중→확인 담당 승인/다시 해줘).
  선생님 화면에 1인1역 역할 만들기, 기초미션 문제은행 가져오기·출제 단원 고르기 추가.
  문제은행 샘플: `data/math-sample.json`(분수·소수의 나눗셈).
  **에뮬레이터에서 학생 흐름 전부 확인함**: 기분(직접 쓰기 포함), 기초미션 5문제(정답 채점·오답·난이도 조정·참여일 1일),
  1인1역(했어요→확인 담당 승인 +4). 포인트가 거래+요약으로 정확히 쌓임(기초미션 4 + 1인1역 4 = 8점).
  선생님 화면(1인1역·기초미션 관리)은 교사 Google 로그인이 자동 브라우저에선 안 돼서(팝업 제약) 손으로 확인 필요.
  시드 도구: `node tools/seed-emu.mjs`(에뮬레이터에 학생 2명·역할·문제은행 넣기).
  규칙 자동 시험 64/65 통과(1개 기존 skip).
- **4단계 (2026-10-17)**: 선생님 오늘 현황(`js/teacher/today.js`), 체크판(`js/teacher/board.js`).
  오늘 현황: 반 전체 기분·기초미션·1인1역·남은 과제 표, 요약·처리할 일 배지, 대신 승인, 부정 기분 행 색, 필터.
  체크판: 과제 만들기·수정·복사·삭제, 빈칸 완료(포인트), 제출 확인/다시 해오기, 모두 완료, 늦으면 절반, 선생님 확인용 구역.
  **에뮬레이터에서 교사 UI로 확인함**: 오늘 현황 렌더·대신 승인(+4), 과제 만들기·완료(+5), 학생1 지갑 9점·거래 2줄 정확.
  (교사 Google 팝업이 자동 브라우저에서 막혀, 에뮬레이터에선 이메일 계정으로 로그인 후 teachers 문서를 넣어 확인함.
  규칙상 교사 판정은 teachers 문서 유무만 봄.)
- **5단계 (2026-10-17)**: 학생 앱 하단 메뉴(대시보드·글마당·과제마당·약속마당) 셸(`js/student/app.js`).
  - 글마당: 글쓰기(임시저장)·하루 1편 +2점·주간 보너스, 피드(전체/내 글)·공감·신고. 교사 글마당 관리(신고 배지·숨기기/수정/삭제+포인트 회수).
  - 과제마당: 해야 할/제출한/지난, 체크·글 제출, 다시 해오기 재제출. 체크판과 연동(제출→파란 점→확인 완료 +포인트, 늦으면 절반).
  - 약속마당: 이야기(이름공개/익명/선생님만보기)·친구 이름 감지 경고·공감·댓글, 우리반 약속. 교사 관리(단계·안건 기준·익명 작성자 확인·선생님만 보기함).
  **에뮬레이터에서 세 기능 전부 UI로 확인함**(공감·신고·제출·확인·포인트 지급/회수·약속 승격). 콘솔 오류 없음.
  주간 보너스는 평일 전용이라 토요일엔 미확인(기획서대로 정상).
- **6단계 (2026-10-17)**: 상점(`js/student/shop.js`)·공동 목표·교사 포인트/목표 관리.
  - 상점: 내 씨앗 나무(누적 포인트 단계·진행 바), 쿠폰 사기(바로구매 즉시/승인형 대기·구매 한도), 내 쿠폰 쓰기(사용 승인 대기), 쿠폰 제안(주 2개).
  - 교사 포인트 관리(`points-admin.js`): 구매 승인/거절(환불), 사용 완료/다음에, 학생별 보유 쿠폰, 학생 제안 상점에 올리기+쪽지, 상점 쿠폰 CRUD.
  - 공동 목표: 상점·대시보드 진행 바, 보태기(1·5·10·직접). 교사 목표 관리(`goals-admin.js`): 만들기·고치기·닫기, 기부 명단(선생님만).
  - 공용 `dates.js`에 `monthId` 추가. 시드에 기본 쿠폰 5종·목표 g1.
  **에뮬레이터 확인**: 바로/승인 구매·구매 한도·사용 완료, 공동 목표 보태기(10/100·1명·지갑 반영). 지갑 60→25, 누적 60 유지, 거래 정확. 콘솔 오류 없음.
- **7단계 (2026-10-17)**: 복셀 3D 캐릭터·아이템·칭호 (`js/character/`).
  - `catalog.js`(아이템 모양+색, 17종), `voxel3d.js`(three.js, 밀어서 회전·머리 위 칭호), `voxel2d.js`(정면 그림, 격자용).
  - 학생 내 캐릭터: 3D 캐릭터, 기본 아이템 자동 지급·착용, 카테고리별 상점(색상별 사고 입기), 칭호 달기(업적 자동+수여), 우리 반 격자(2D, 눌러서 3D 팝업).
  - 교사 캐릭터·칭호 관리(`character-admin.js`): 아이템 판매/숨김·기본값 넣기, 칭호 수여(금색)·회수.
  - 스마트보드 `board.html`(`board.js`): 반 전체 캐릭터 3D 회전.
  - 아이템 메타(가격·판매)는 Firestore items, 모양은 정적 도감. three.js는 jsdelivr CDN(0.160.0).
  **에뮬레이터 확인**: 3D 렌더·머리 노랑 구매(-8)+착용 즉시 반영, 칭호 달기(머리 위 표시), 우리 반 격자·친구 3D 팝업, 교사 관리·수여, board.html 3D 회전. 콘솔 오류 없음.
  이후 캐릭터 개선 커밋: 표정(눈·입·볼) 또렷하게, 기본색 분리(갈색머리·파란셔츠·검정바지·흰신발), 머리 얼굴 감싸기, 바닥 그림자.
- **8단계 (2026-10-18)**: 나의마당·선생님 쪽지·살핌판·백업/복원/초기화. **마지막 단계 — 기획서 개발 순서 1~8 모두 완료.**
  - 나의마당(`js/student/myweek.js`): 이번/지난주 과제·포인트·기분 흐름·기초미션 참여도장·글마당 보너스.
  - 선생님 쪽지: 대시보드 맨 위 카드 + 읽었어요.
  - 살핌판(`js/teacher/care.js`): 자기관리 현황 표, 살펴볼 학생(마음·과제·활동), 선택 일괄 쪽지·포인트(지급/지급취소/차감), 메모.
  - 백업·초기화(`js/teacher/admin.js`): 전체 백업 내려받기, 복원, 학년말 초기화(설정·문제은행·상점 틀 보존).
  **에뮬레이터 확인**: 나의마당 렌더, 쪽지 전송→표시→읽음, 살핌판 지급 +10(지갑·누적·학생 나의마당 반영), 백업 전체 읽기. 콘솔 오류 없음.

## 🎉 전체 완료 + 배포

  - 선생님이 콘솔에서 로그인 방법(익명·Google) 켜고, 교사 등록·기본 설정·학생 명단까지 직접 확인함(1~4단계).
- **기초미션 실제 문제은행 (2026-10-18)**: `data/math-6-2.json` — 2022 개정 6-2 천재교과서(한대희) 6단원 156문제(기초/보통/도전, 숫자·객관식). 교사 기초미션 화면에 '6학년 2학기 문제은행 가져오기' 버튼. 단원명은 "1. 분수의 나눗셈" 형식. **정답은 선생님 검토 권장**(특히 공간과 입체는 그림 없이 '위에서 본 모양의 수'로 서술).

## 기획서와 달라진 결정 (사용자 확인 완료)
- 기초미션: 하루 5문제, 맞힌 개수만큼 1점씩, 재시도 없음, 틀리면 다음 문제를 쉽게. 5문제를 모두 풀어야 참여일 1일
- 기분: 그날 안에서는 다시 고를 수 있음. 직접 쓴 기분은 본인과 교사만 봄
- PIN: 숫자 4자리
- 로그인 전 번호 → 학생ID 조회용 `numbers` 컬렉션 추가 (이름·PIN 없음)

## 새 컴퓨터 준비
1. Node.js, Git 설치
2. 프로젝트 가져오기 → 폴더에서 `npm install`
   - 지금은 USB로 옮긴다: `class-app-날짜.zip`(node_modules 제외, .git 포함)을 풀어서 쓴다.
   - 옮기기 전에 커밋하고, 압축은 바탕화면에 만든다. 두 컴퓨터에서 동시에 고치지 않는다.
3. 규칙 시험을 돌리려면 Java 21 설치 (`winget install EclipseAdoptium.Temurin.21.JRE`)와 `npm install -g firebase-tools`
4. 앱 띄우기: `npm run serve` → http://localhost:5500 (진짜 Firebase), 에뮬레이터는 `npm run emu` 후 주소에 `?emu`
