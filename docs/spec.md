# 학급관리 웹앱 기획서

Oct 15, 2026 · @진쌤

## 개요

학생은 디벗으로 접속해 매일 할 일과 과제를 스스로 챙기고 포인트를 모으며, 교사는 대시보드에서 반 전체의 하루와 흐름을 한눈에 본다.

- 접속: 학급 주소(QR) → 번호 + PIN 로그인. 이메일·실명 계정 없음
- 기술: Firebase(Firestore + 호스팅), 무료 요금제 범위. 사진 업로드 없음
- 개인정보: 학생 문서에는 번호, 이름, PIN만. 학년말 전체 초기화 기능 제공
- 3D 캐릭터: three.js 복셀 방식

| 구분 | 메뉴 |
| --- | --- |
| 학생 | 대시보드, 글마당, 약속마당, 과제마당, 나의마당, 내 캐릭터, 상점 (+ 건의함 버튼) |
| 선생님 | 오늘 현황, 체크판, 살핌판, 글마당 관리, 약속마당 관리, 1인1역, 포인트 관리, 캐릭터·칭호 관리, 관리 페이지 |

## 공통 규칙: 포인트

포인트는 숫자 하나로 저장하지 않고 거래 기록(+2 기초미션, −30 자유자리권 등)을 쌓아 합산한다. 학생이 값을 조작할 수 없고, 내역 확인이 쉽다.

- 지갑 포인트: 받은 것 − 쓴 것. 상점, 반 목표 기부에 사용
- 누적 포인트: 지금까지 받은 합계. 씨앗 나무 성장 기준이며 써도 줄지 않음
- 교사 조정 두 종류: 지급 취소(지갑·누적 모두 감소, 실수 정정용), 차감(지갑만 감소, 생활 지도용). 둘 다 사유 필수, 학생 내역에 표시
- 화폐 이름은 관리 페이지에서 변경 가능

| 활동 | 포인트 | 비고 |
| --- | --- | --- |
| 기분 고르기 | 0 | 기록만 |
| 기초미션 | 하루 5문제, 정답 1문제당 1 (재시도 없음) | 설정에서 변경 |
| 1인1역 | 4 | 확인 담당 승인 후 지급 |
| 글마당 | 2 (하루 1회) | 한 주 서로 다른 3일 쓰면 보너스 3 |
| 과제 | 과제별 설정 | 마감 뒤에 내면 0점 (선생님이 직접 완료하면 그대로) |

하루 약 11점(기초미션 최대 5 + 1인1역 4 + 글마당 2), 한 주 약 55점이 가격과 칭호 기준의 바탕이다.

## 학생: 대시보드

첫 화면은 오늘 남은 할 일 수와 포인트를 가장 먼저 보여준다.

화면 순서 (위에서 아래로)

1. 새소식 팝업, 선생님 쪽지 카드 (확인 전까지 표시)
2. 내 캐릭터(작게), 이름, 지갑 포인트, 오늘 남은 할 일 수와 진행 바
3. 친구 확인 요청 (내가 1인1역 확인 담당일 때만): 승인 / 다시 해줘
4. 오늘 할 일: 기분 고르기, 기초미션, 1인1역 중 안 한 것. 1인1역은 요청중 상태 표시
5. 오늘 한 일: 완료 항목과 받은 포인트
6. 선생님 과제: 과제명, 마감(D-day), 보상, 상태. 마감 임박 순
7. 우리반 공동 목표 진행 바
8. 선생님 확인용 알림 (가정통신문 회신 등, 미제출 학생에게만)

오른쪽 위에 작은 **건의함** 버튼.

### 매일 할 일 규칙

- **기분 고르기**: 신나요, 좋아요, 보통이에요, 속상해요, 화나요, 힘들어요 중 하나 또는 '직접 쓸래요'(한 줄, 본인과 선생님만 봄). 그날 안에서는 다시 고를 수 있음. 포인트 없음
- **기초미션**: 하루 5문제. 선생님이 고른 단원에서 학생마다 다른 문제 무작위 출제. 처음엔 보통 난이도, 틀리면 다음 문제는 같은 단원 기초 문제, 정답률이 계속 낮으면 기초부터 시작. 재시도 없이 맞힌 개수만큼 포인트. 5문제를 모두 풀면 그날 참여일 1일
- **1인1역**: '했어요' → 요청중 → 확인 담당 승인 시 4점. 확인 담당은 '다시 해줘' 가능. 담당 결석·미확인 시 선생님 대신 승인

### 건의함

- 앱이 이상해요: 메뉴 선택 + 내용. 접속 시각, 화면, 기기 정보 자동 첨부
- 이런 게 있었으면 좋겠어요: 새 기능 / 아이템 / 기타
- 하루 3건 제한. 선생님만 봄

## 학생: 글마당, 약속마당, 과제마당

### 글마당 (독서 감상)

- 글쓰기: 날짜(읽은 날 표시용, 기본 오늘), 책 제목, 줄거리, 내 생각과 느낌. 글자 수 표시, 임시저장
- 하루 1회 제한과 포인트는 실제 올린 날 기준. 주는 월\~금
- 친구 글: 카드 배열(책 제목, 작성자, 날짜, 앞 두세 줄), 누르면 확대. 전체 / 내 글 필터
- 공감 버튼만 (1인 1회, 내 글 불가, 숫자만 표시)
- 신고: 사유 선택(놀리는 말, 욕설, 기타) → 즉시 숨김 → 선생님 확인 후 복구/삭제. 신고자 비공개, 중복 신고 불가
- 삭제된 글은 포인트와 해당 주간 보너스 회수

### 약속마당 (우리 반 이야기 → 약속)

- 이야기올리기: 공개 방식 선택(이름 공개 / 익명 / 선생님만 보기)
- 필수 칸: 우리 반이 이러면 좋겠어요, 왜 그렇게 생각했나요
- '더 자세히 쓸래요' 펼침: 언제 그런 일이 있었나요, 무슨 일이 있었나요, 그때 내 마음은 어땠나요
- 공개 글에 반 친구 이름이 들어가면 올리기 전 경고 → 선생님만 보기로 전환 제안
- 익명은 친구에게만 익명, 선생님은 작성자 확인 가능 (학생에게 사전 안내)
- 공감 5개 이상이면 자동으로 회의 안건 (기준 수는 설정). 선생님만 보기 글은 공감·안건 대상 아님
- 댓글 '이렇게 하면 좋을 것 같아요' (이름 공개, 이름 감지·신고 적용)
- 단계: 이야기 → 회의 안건 → 우리반 약속 / 보류. 약속은 따로 모아 표시
- 포인트 없음

### 과제마당

- 탭: 해야 할 과제 / 제출한 과제 / 지난 과제
- 카드: 제목, 과목, 마감(D-day), 포인트, 상태
- 제출 방식은 과제별: 체크만 / 글
- 흐름: 제출 → 확인 대기 → 완료(포인트) 또는 다시 해오기(코멘트) → 재제출
- 마감 판정은 처음 제출 시각 기준. 마감 뒤에 낸 것은 완료 표시만 하고 0점. 선생님이 체크판 빈칸을 눌러 바로 완료하면(결석 등) 포인트 그대로
- 대상 지정 과제는 해당 학생에게만 표시
- 숙제면제권 사용 시 '면제' 처리, 포인트 없음

## 학생: 나의마당, 내 캐릭터, 상점

### 나의마당 (이번 주 내 상태, 월\~금, 지난주 넘겨보기)

- 과제: "5개 중 3개 완료" 진행 바, 남은 과제(마감 임박 순), 마감 지난 미제출은 빨간색
- 포인트: 이번 주 받은/쓴 합계 + 날짜순 내역
- 기분 흐름: 월\~금 이모지 다섯 칸 (본인과 선생님만)
- 기초미션: 요일별 참여 도장 + 이번 주 정답률
- 독후감상글: 이번 주 쓴 글 목록 + 주간 보너스 진행("3일 중 2일")

### 내 캐릭터

- 왼쪽: 복셀 3D 캐릭터, 밀어서 360도 회전. 머리 위에 칭호 표시(항상 정면)
- 오른쪽: 내 아이템(카테고리별), 내 칭호, 아이템 상점
- 아이템은 블록 묶음 단위로 교체, 색은 같은 모양에 색만 변경. 색마다 가격 별도
- 처음 지급(무료): 기본 머리, 기본 얼굴, 무지 티셔츠, 기본 바지, 운동화 + 기본 색 선택

'내 캐릭터 / 우리 반' 탭: 우리 반 탭은 반 전체 캐릭터를 정면 그림으로 격자 배열하고 이름, 칭호만 표시(포인트 비공개). 친구를 누르면 그 캐릭터만 3D로 열려 돌려볼 수 있음(디벗 성능 고려).

| 카테고리 | 아이템 |
| --- | --- |
| 헤어 | 기본 머리(다른 색), 하나로 묶은 머리, 단발, 파마, 양갈래, 긴 머리, 뾰족 머리, 스포츠 머리 |
| 얼굴 | 웃는 눈, 윙크, 반짝 눈, 졸린 눈, 놀란 얼굴 |
| 상의 | 후드티, 셔츠, 줄무늬 티, 체육복, 멜빵, 정장, 마법사 로브, 다이아 갑옷 |
| 하의 | 반바지, 치마, 청바지, 트레이닝 바지, 다이아 하의 |
| 머리소품 | 모자, 머리띠, 리본, 헤드폰, 왕관, 비니, 해적 모자, 고양이 귀, 강아지 귀, 도깨비 뿔, 꽃 장식, 다이아 헬멧 |
| 얼굴소품 | 안경, 선글라스, 마스크, 반창고, 별 스티커, 로봇 가면 |

가격: 기본 머리 다른 색 5\~10, 일반 15\~25, 특별(정장, 로브, 해적 모자, 도깨비 뿔 등) 40\~60, 다이아 세트·왕관 각 100 이상. 다이아 세트는 특정 게임을 닮지 않은 오리지널 디자인. 남녀 구분 없음.

### 칭호 (업적 자동 획득 + 선생님 수여, 상점 판매 없음, 학생 제작 불가)

| 단계 (글자 색) | 독서 (글마당 편수) | 기초미션 (참여일) | 1인1역 (완료일) |
| --- | --- | --- | --- |
| 초보 (흰색) | 10 초보 독서가 | 10 초보 수학 탐험가 | 20 초보 도우미 |
| 중급 (초록) | 20 중급 독서가 | 30 중급 수학 탐험가 | 40 중급 도우미 |
| 고급 (파랑) | 30 고급 독서가 | 50 고급 수학 탐험가 | 60 고급 도우미 |
| 마스터 (보라) | 50 마스터 독서가 | 80 마스터 수학 탐험가 | 100 마스터 도우미 |
| 그랜드마스터 (금색) | 70 그랜드마스터 독서가 | 120 그랜드마스터 수학 탐험가 | 150 그랜드마스터 도우미 |

삭제된 글, 결석 처리한 날은 계산에서 제외. 선생님 수여 칭호는 금색 전용. 한 번에 칭호 하나만 착용.

### 상점

| 쿠폰 | 가격 | 한도 |
| --- | --- | --- |
| 준비물 대여권 | 5 | 1인 주 2장 |
| 급식 먼저 먹기권 | 15 | 반 전체 하루 1명 |
| 간식권 | 20 | 1인 주 1장 |
| 자유자리권 | 30 | 반 전체 하루 3명 |
| 숙제면제권 | 50 | 1인 월 1장 |

- 바로 구매 쿠폰은 즉시 지급, 아닌 쿠폰은 신청 시 포인트 보류 → 선생님 승인 시 지급 / 거절 시 환불
- 사용: '쓸래요' → 선생님 '사용 완료'. 하루 한도 초과 시 "내일 써주세요" 안내
- 맨 아래 '이런 쿠폰이 있으면 좋겠어요': 무엇을, 몇 포인트, 왜 → 보내기 (1인 주 2개)
- **내 씨앗 나무** (누적 포인트 기준, 다음 단계까지 진행 바): 새싹 0\~100, 줄기 101\~250, 어린 나무 251\~500, 꽃 피는 나무 501\~800, 열매 나무 801\~1,200, 큰 나무 1,201 이상
- **우리반 공동 목표**: 제목, 진행 바, 모인/남은 포인트, 보태기(1, 5, 10, 직접 넣기) + 내 지갑 포인트. 보태기 전 확인, 보유·남은 포인트 초과 불가, 인원수만 공개("12명이 보탰어요"), 달성 시 축하 화면 후 보태기 닫힘

## 선생님: 오늘 현황, 체크판, 살핌판

### 오늘 현황 (첫 화면)

- 맨 위 요약: "기분 22/25 · 기초미션 18/25 · 1인1역 20/25" + 처리할 일 배지(신고, 쿠폰 요청, 과제 확인 대기, 1인1역 대신 승인, 선생님만 보기 이야기, 연속 부정 기분 알림, 1인1역 희망 받기 알림)
- 표: 번호 · 이름 · 기분 · 기초미션(맞힌 수/5) · 글마당 · 1인1역(완료/요청중/미완료) · 남은 과제(늦음 표시)
- 속상해요·화나요·힘들어요, 직접 쓴 기분(말풍선, 눌러서 내용 보기)은 행에 색 표시
- 3일 연속 부정 기분이면 "○○이 3일째 마음이 힘들어 보여요" 알림
- 요청중 칸 눌러 대신 승인, 남은 과제 숫자 눌러 목록, 이름 눌러 학생의 나의마당
- '아직 안 한 학생만 보기' 필터

### 체크판 (과제 관리 포함)

- 가로 학생(번호·이름), 세로 과제명·기한. 과제명 칸 고정, 학생 쪽만 가로 스크롤
- 칸 상태: 빈칸(안 함), 파란 점(확인 대기 → 눌러 확인/다시 해오기), ✓ 완료(늦은 완료는 주황), ↺ 다시 해오기, 면(면제권), 회색(대상 아님)
- 빈칸을 직접 누르면 즉시 완료 + 포인트. 과제별 '모두 완료' 버튼
- 맨 아래 줄: 학생별 남은 과제 / 미회신 따로. 오른쪽 칸: 과제별 "완료 18/25"
- 오래 지나 모두 끝난 과제는 자동 접기
- **+ 항목 추가**: 종류(학생 과제 / 선생님 확인용), 제목, 설명, 과목, 마감, 제출 방식(체크/글), 포인트(마감 뒤 제출은 0점), 대상(전체/선택), 학생 대시보드 알림(확인용)
- 과제명 눌러 수정·삭제, 복사해서 새로 만들기, 매주 반복
- 선생님 확인용(가정통신문 회신 등)은 아래 구역에 따로, 포인트 없음, 과제마당에 안 보임

### 살핌판

위 구역 '살펴볼 학생' (기준은 설정에서 변경)

- 마음: 최근 5일 중 3일 이상 부정 기분, 직접 쓴 기분 반복
- 과제: 남은 과제 2개 이상, 최근 2주 늦은 제출·다시 해오기 반복
- 활동: 최근 2주 기초미션·1인1역·글마당 완료율 50% 미만
- 갑작스러운 변화: 평소 대비 이번 주 완료율 급락 (예: 3주 평균 90% → 30%)
- 학생마다 이유 한 줄. 이름 누르면 2주 기분·완료율 상세 + 메모. '살펴봤어요' 누르면 목록에서 내려가고, 지속되면 일주일 뒤 다시 표시

아래 구역 '자기관리 현황' (반 전체, 열 제목 눌러 정렬)

| 번호 | 이름 | 기초미션 | 정답률 | 최근 기분 | 지갑 | 누적 |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 예시 | 4/5일 | 82% | 최근 3일 이모지 | 46 | 312 | 쪽지 · 포인트 |

- 쪽지: 한 명 또는 여러 명, 학생 대시보드 맨 위 카드, '읽었어요' 시 읽음 표시. 답장 없음
- 포인트: 지급 / 지급 취소 / 차감, 사유 필수, 여러 명 일괄 가능
- 살핌판은 학생에게 전혀 보이지 않음

## 선생님: 관리 메뉴

### 글마당 관리

- 학생 화면과 같은 카드 배열. 신고된 글은 빨간 배지로 맨 앞
- 검색: 책 제목, 학생 이름. 필터: 월별, 날짜 범위, 학생, 상태(공개/숨김/신고됨), 중복 적용
- 숨기기: 친구에게만 안 보임, 작성자는 "선생님이 숨긴 글"로 확인, 포인트 유지, 다시 공개 가능
- 삭제: 포인트·주간 보너스 회수
- 수정: "선생님이 고친 글" 표시

### 약속마당 관리

- 안건 공감 기준 수 조절, 게시글 가리기
- 안건 아래 '우리가 정한 것' 기록 → 확정 시 우리반 약속 목록에 자동 등록
- 비슷한 이야기 합치기 (공감 중복은 1회로, 작성자에게 안내)
- 회의 화면: 스마트보드용 크게 보기, 회의하며 바로 결과 기록
- 약속 점검: 확정 3주 뒤 "잘 지켜지고 있나요?" 재게시 → 유지 / 고치기 / 없애기 (약속별 시기 변경 가능)
- 선생님만 보기 이야기함: 상담 메모, 익명 글 작성자 확인

### 1인1역

- 오늘 현황: 역할 · 담당 · 확인 담당 · 상태(미완료/요청중/완료/다시 해줘) · 대신 승인. 결석 표시 시 완료율·칭호 계산 제외
- 기록: 학생 × 요일 표, 역할별 완료율, 확인 담당의 처리 속도
- 역할 설정: 이름, 하는 일, 담당(2명 가능), 확인 담당, 역할별 포인트
- 교체: 2주 주기. 끝나기 3일 전 "희망 받기를 열까요?" 알림 → 학생 1\~3지망 → 자동 배정(직전 2·3지망 학생 우선, 같은 역할 연속 회피, 미제출자는 남은 역할) → "1지망 18명 · 2지망 5명" 요약, 끌어서 조정 → 확정. 확인 담당 자동 지정(자기 역할 제외). 이전 기간 기록 보관

### 포인트 관리

1. 쿠폰 요청: 구매 신청(승인/거절) + 사용 요청(사용 완료/다음에). 학생별 보유 쿠폰 현황
2. 학생 제안: '상점에 올리기'(내용 미리 채운 등록 창, 가격·한도 수정) → 제안 학생에게 자동 쪽지 / 삭제
3. 상점 관리: 쿠폰 이름, 설명, 포인트, 바로 구매 체크, 구매 한도, 하루 사용 한도, 판매 중/숨김, 순서
4. 공동 목표: 제목·목표 포인트·보상 수정, 기부 학생 명단과 금액(선생님만), 지난 목표 기록

### 캐릭터·칭호 관리

- 아이템 가격·색 조정, 판매 중/숨김
- 칭호 수여(학생 선택 후 지정), 업적 칭호 이름·기준 수정

우리 반 캐릭터 전체 화면(스마트보드용): 교사용 데스크탑에서 반 전체 캐릭터를 3D로 한꺼번에 띄우고 천천히 회전. 이름, 칭호 표시, 포인트 비공개. class.html에서 링크로 연결.

### 관리 페이지

- 새소식: 제목, 내용, 게시 기간 → 학생 첫 화면 팝업, '확인했어요' 후 미표시, 읽은 인원 확인
- 이름 바꾸기: 메뉴 이름, 화폐 이름
- 기초미션 출제 범위: 학년, 학기, 단원 체크 (단원 이름 수정 가능)
- 학생 명단: 번호·이름 등록(엑셀 붙여넣기), PIN 발급·재설정, 전학 처리
- 건의함: 상태(확인함 / 고쳤어요 / 반영할게요), 처리 시 학생에게 자동 쪽지
- 데이터: 전체 백업 내려받기, 백업에서 복원, 학년말 전체 초기화
- 접속 QR코드
- 설정: 활동별 포인트, 칭호 기준, 공감 기준, 살핌판 기준

## 기초미션 문제은행과 다음 단계

문제은행은 Claude가 성취기준에 맞춘 새 문제로 만들고, 내용 주제 기준으로 분류한 뒤 천재교과서(한대희) 단원 이름을 붙인다.

- 태그: 학년, 학기, 내용 주제, 단원 이름, 난이도(기초/보통/도전), 정답
- 답 형식: 숫자, 분수(약분 전후 모두 정답), 객관식만. 서술형 없음
- 분량: 단원당 난이도별 10\~15문제로 시작
- 정답은 선생님 검토 후 반영

### 남은 확인 사항

- 천재교과서(한대희) 6학년 수학 차례 (단원 이름·순서 맞추기용)

### 개발 순서 (제안)

1. Firebase 구조: 학생, 포인트 거래 기록, 과제, 글, 이야기, 1인1역, 아이템, 설정
2. 로그인(번호 + PIN)과 관리 페이지의 학생 명단
3. 학생 대시보드 + 기분, 1인1역, 기초미션
4. 선생님 오늘 현황, 체크판
5. 글마당, 과제마당, 약속마당과 각 관리 화면
6. 상점, 포인트 관리, 씨앗 나무, 공동 목표
7. 복셀 캐릭터, 아이템, 칭호
8. 나의마당, 살핌판, 백업·초기화
